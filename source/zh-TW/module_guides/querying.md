查詢是您的 LLM 應用程式中最重要的一部分。要了解如何獲得可部署的最終產品，請查看 [query engine](/python/framework/module_guides/deploying/query_engine/)、[chat engine](/python/framework/module_guides/deploying/chat_engines/)。

如果您希望結合進階推理與工具使用，請查看我們的 [agents](/python/framework/module_guides/deploying/agents/) 指南。

## Query Workflows

您可以使用我們事件驅動的 `Workflow` 介面輕鬆建立 workflows 以進行查詢。請查看我們的 [workflow](https://developers.llamaindex.ai/python/framework/module_guides/workflow/) 指南以了解更多詳情。

否則，請查看如何將我們的 query modules 作為獨立元件使用 👇。

---
title: "全端網路應用程式"
---

LlamaIndex 可以整合到下游的全端 Web 應用程式中。它可以用於後端伺服器（例如 Flask），打包到 Docker 容器中，以及/或直接在 Streamlit 或 CopilotKit 等框架中使用。

我們提供教學和資源，幫助您在此領域開始：

- **[全端應用程式指南](/python/framework/understanding/putting_it_all_together/apps/fullstack_app_guide/)** 示範如何使用 LlamaIndex 作為 API 並搭配 TypeScript+React 前端來建置應用程式。

- **[Fullstack Application with Delphic](/python/framework/understanding/putting_it_all_together/apps/fullstack_with_delphic/)** 帶您使用 LlamaIndex 並搭配一個名為 Delphic 的生產就緒 Web app 啟動範本。

- **[LlamaIndex Starter Pack](https://github.com/logan-markewich/llama_index_starter_pack)** 為 LlamaIndex 提供非常基礎的 flask、Streamlit 和 Docker 範例。

- **CopilotKit + LlamaIndex：** CopilotKit 是 Agentic Application Framework，一個用於 AI 輔助應用程式的開源框架和託管服務。

  - [CopilotKit LlamaIndex Quickstart](https://docs.copilotkit.ai/llamaindex/quickstart)：如何在 10 分鐘內將您的 LlamaIndex Agents 轉變為 agent-native 應用程式的指南。
  - [CopilotKit <> LlamaIndex Starter](https://github.com/CopilotKit/with-llamaindex)：這是使用 LlamaIndex 和 CopilotKit 建置 AI agents 的啟動範本。它提供了一個現代的 Next.js 應用程式，內建了可以研究股票、分析市場資料並提供投資見解的 investment analyst agent。
  - [CopilotKit LlamaIndex Channels SDK](https://docs.copilotkit.ai/slack/llamaindex)：使用 CopilotKit Channels SDK 在 Slack 和其他訊息平台中運行相同的 LlamaIndex agent 作為機器人的指南。
